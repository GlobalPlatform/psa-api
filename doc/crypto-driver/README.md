# PSA Crypto Driver Interface &mdash; specification sources

The Crypto Driver Interface specification source files are organized as follows:

Folder | Content
-- | --
Current directory | Configuration and table of contents
`about` | Front matter
`overview` | Purpose, goals, and architecture
`common` | Contracts shared by the Dispatch and Driver interfaces
`description` | Driver-description information model and serialization
`api` | Dispatch, Driver, and supporting-service interface references
`integration` | Driver packaging, integration, and migration guidance
`appendix` | Appendices
`figure` | Image files
